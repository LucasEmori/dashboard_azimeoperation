# Brand Specification - Dashboard Joias

## Paleta Alinare (Lado Esquerdo)

- **Background/Primary**: `#1a237e` - Azul marinho escuro
- **Foreground/Text**: `#ffffff` - Branco
- **Accent**: `#3949ab` - Azul mais claro para destaques (derivado)
- **Surface**: `#283593` - Azul levemente mais claro para cards

A paleta da Alinare transmite profissionalismo, confiança e estabilidade com forte contraste.

## Paleta Novitah (Lado Direito)

- **Background/Primary**: `#a07a7a` - Marrom-avermelhado/malha suave
- **Foreground/Text**: `#ffffff` - Branco
- **Accent**: `#b88e8e` - Tom mais claro para destaques (derivado)
- **Surface**: `#8d6b6b` - Tom mais escuro para cards

A paleta da Novitah é quente e sofisticada, com um tom terroso que evoca elegância.

## Layout Geral

O dashboard utiliza um layout dividido verticalmente:
- **Esquerda (50%)**: Dados da Alinare com fundo azul marinho
- **Direita (50%)**: Dados da Novitah com fundo marrom-avermelhado

## Tipografia

- Fonte principal: System sans-serif para legibilidade em dados
- Números/métricas: System font com tabular nums para alinhamento
